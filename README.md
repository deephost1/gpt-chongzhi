## 一、国内的卡为什么付不了款

OpenAI 的收款交给 Stripe 处理。Stripe 只认境外发行的 Visa、Mastercard、American Express 信用卡，而且账单地址要和发卡地对得上。国内的储蓄卡、银联卡，连同大部分双币卡，基本都会被拒。这跟你卡里有多少钱、征信好不好没有关系，卡在的是发卡地这道门槛。支付宝、微信、PayPal 也都不在官方支持之列。

换句话说，国内开通 ChatGPT Plus 的各种办法，归根结底都在解决同一个问题：**怎样把这笔海外支付付出去。**

还有一点要当心：同一个账号反复绑卡失败，会触发 Stripe 的风控。轻一点，冷却期内付不了款；严重的话，支付功能会被长期锁住。卡被拒一两次就该收手了，换条路走。
